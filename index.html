🚀 Xuất Bản Lên Tên Miền Riêng (.id.vn)

Trình Cấu Hình Firebase & Đóng Gói File index.html

Để chạy trang web này trên tên miền .id.vn của bạn (qua GitHub Pages hoặc Vercel), hãy tạo một dự án miễn phí tại console.firebase.google.com (bật Authentication: Google & Anonymous và Cloud Firestore), sau đó dán đoạn mã firebaseConfig và Gmail Admin của bạn vào đây:

🛡️ Quy tắc Firestore Rules khuyên dùng:

Dán vào mục Firestore Database → Rules trên Firebase Console để bảo vệ dữ liệu phòng học: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
    match /artifacts/{appId}/users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
